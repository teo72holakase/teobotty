PASO 1 - INSTALAR DEPENDENCIAS
──────────────────────────────────────────────────────────────────────────────────

Abre PowerShell y ejecuta:

cd C:\Users\teo72\Downloads\teobot

PASO 2 - VERIFICAR QUE TODO ESTÁ INSTALADO
──────────────────────────────────────────────────────────────────────────────────

Ejecuta:

──────────────────────────────────────────────────────────────────────────────────

Ejecuta:

python main.py

PRUEBA LOS COMANDOS EN DISCORD
──────────────────────────────────────────────────────────────────────────────────

En cualquier canal de tu servidor Discord, escribe:

/dice
/8ball
/lock
/userinfo

Los comandos deberían aparecer en el menú desplegable.


PARA DETENER EL BOT
──────────────────────────────────────────────────────────────────────────────────

Presiona: Ctrl + C

En PowerShell verás:

  Shutting down...


SOLUCIONAR PROBLEMAS
──────────────────────────────────────────────────────────────────────────────────

❌ Error: ModuleNotFoundError: No module named 'discord'
✅ Solución: pip install -r requirements.txt

❌ Error: DISCORD_TOKEN not found
✅ Solución: Abre .env y asegúrate que tienes tu token:
           DISCORD_TOKEN=tu_token_aqui

❌ Los comandos no aparecen en Discord
✅ Solución: Ejecuta en Discord: /sync

❌ Error: Port already in use
✅ Solución: Ya hay otro bot corriendo. Busca en ProcessExplorer y ciérralo


VERIFICACIONES FINALES
──────────────────────────────────────────────────────────────────────────────────

✅ .env contiene tu DISCORD_TOKEN
✅ Bot está invitado a tu servidor Discord
✅ Python 3.8+ instalado
