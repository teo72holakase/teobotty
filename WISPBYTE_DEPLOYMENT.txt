PASOS PARA DESPLEGAR EN WISPBYTE:
──────────────────────────────────────────────────────────────────────────────────

1️⃣  CREAR CUENTA EN WISPBYTE
   - Ve a: https://wispbyte.com
   - Regístrate
   - Crea un nuevo bot/proyecto

2️⃣  CONECTAR REPOSITORIO (GIT)
   Opción A - Usar GitHub:
   - Sube el proyecto a GitHub
   - Conecta tu repositorio GitHub en Wispbyte

   Opción B - Upload Manual:
   - Sube todos los archivos a Wispbyte

3️⃣  CONFIGURAR VARIABLES DE ENTORNO
   En la dashboard de Wispbyte:
   - Ve a "Environment Variables" o "Settings"
   - Agrega:
     DISCORD_TOKEN=tu_token_aqui
     DATABASE_PATH=./bot_data.db

4️⃣  INICIAR EL BOT
   - Click en "Deploy" o "Start"
   - El bot debería iniciar automáticamente

5️⃣  VERIFICAR QUE FUNCIONA
   - Revisa los logs en Wispbyte dashboard
   - Deberías ver: "✅ Bot logged in as TeoBotty#XXXX"

⚠️  IMPORTANTE - VARIABLES DE ENTORNO:
──────────────────────────────────────────────────────────────────────────────────

NUNCA subas tu archivo .env real a internet. En su lugar:

1. En tu máquina local:
   - Usa .env con tu token real

2. En Wispbyte:
   - Usa las variables de entorno del dashboard
   - Configura: DISCORD_TOKEN=tu_token_de_discord

3. Crea un .gitignore para que no suba archivos sensibles:
   .env
   bot_data.db
   __pycache__/
   *.pyc
   .DS_Store

TROUBLESHOOTING:
──────────────────────────────────────────────────────────────────────────────────

Problema: Bot no inicia en Wispbyte
Solución: 
  1. Revisa los logs en el dashboard
  2. Verifica que DISCORD_TOKEN esté configurado
  3. Asegúrate que el bot esté invitado al servidor

Problema: ModuleNotFoundError
Solución:
  1. Verifica que requirements.txt tenga todas las dependencias
  2. Asegúrate que audioop-lts está incluido (para Python 3.14)

Problema: Bot se detiene después de iniciar
Solución:
  1. Revisa si hay errores en los logs
  2. Verifica que el token sea válido
  3. Comprueba permisos del bot en Discord


ACTUALIZAR EL BOT EN WISPBYTE:
──────────────────────────────────────────────────────────────────────────────────

2. Haz commit y push a GitHub (si usas GitHub)
3. Wispbyte debería redeploy automáticamente
4. O haz click en "Redeploy" manualmente en el dashboard
