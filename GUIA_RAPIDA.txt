🎯 COMANDOS DISPONIBLES
══════════════════════════════════════════════════════════════════════════════════

MODERACIÓN:
  /lock
  /unlock
  /tempmute @user 60
  /rolve @user @role
  /userinfo @user
  /serverinfo

BIENVENIDA:
  /set_welcome #canal "Bienvenido {user}"
  /set_farewell #canal "Adiós {user}"
  /test_welcome

AUTOROLES:
  /add_autorole @role
  /remove_autorole @role
  /list_autoroles

REACTION ROLES:
  /add_reaction_role 123456 👍 @role
  /remove_reaction_role 123456 👍

TRIGGERS:
  /add_trigger "palabra" "respuesta"
  /remove_trigger "palabra"
  /list_triggers

🔑 PASOS PARA OBTENER BOTÓN
══════════════════════════════════════════════════════════════════════════════════

1. https://discord.com/developers/applications
2. New Application → Add Bot
3. Copiar TOKEN
4. OAuth2 → URL Generator → bot → administrator → copiar URL
5. Abre URL en navegador para invitar bot

══════════════════════════════════════════════════════════════════════════════════
❌ ERRORES COMUNES
══════════════════════════════════════════════════════════════════════════════════

"DISCORD_TOKEN not found"
→ Edita .env con: notepad .env

"No module named 'discord'"
→ pip install -r requirements.txt

"Connection refused"
→ Token inválido o bot no invitado

"python: command not found"
→ Reinstala Python (marca "Add Python to PATH")
