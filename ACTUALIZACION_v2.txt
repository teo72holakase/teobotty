🚀 PASOS PARA USAR TEOBOOTTY:
──────────────────────────────────────────────────────────────────────────────────

LOCAL:
   1. pip install -r requirements.txt
   2. Edita .env con tu DISCORD_TOKEN
   3. python main.py

WISPBYTE HOSTING:
   1. Lee WISPBYTE_DEPLOYMENT.txt
   2. Conecta tu repositorio o sube los archivos
   3. Configura DISCORD_TOKEN en variables de entorno
   4. Haz click en Deploy
   5. ¡Listo! TeoBotty estará 24/7 online
