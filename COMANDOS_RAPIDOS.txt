NOTA: Ejecuta estos comandos en PowerShell o CMD en la carpeta: c:\Users\teo72\Downloads\teobot


📌 PASO 1: INSTALAR DEPENDENCIAS
═══════════════════════════════════════════════════════════════════════════════════

Opción A - SIN Entorno Virtual (Rápido):
─────────────────────────────────────────
pip install -r requirements.txt


Opción B - CON Entorno Virtual (Recomendado):
──────────────────────────────────────────────

PowerShell:
───────

.\venv\Scripts\Activate.ps1
pip install -r requirements.txt

CMD:
───
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt


📌 PASO 2: CONFIGURAR TOKEN
═══════════════════════════════════════════════════════════════════════════════════

1. Copiar archivo de ejemplo:
   copy .env.example .env

2. Editar .env con tu token:
   - Abre .env con Notepad (notepad .env)
   - Cambia: DISCORD_TOKEN=tu_token_aqui
   - Por tu token real (sin comillas, solo el token)
   - Guarda (Ctrl+S)


📌 PASO 3: EJECUTAR EL BOT
═══════════════════════════════════════════════════════════════════════════════════

Opción A - Ejecución Normal:
────────────────────────────
python main.py

Deberías ver:

✅ Loaded cog: moderation
✅ Loaded cog: welcome
✅ Loaded cog: roles
✅ Loaded cog: triggers
✅ Bot logged in as TeoBot#XXXX


Opción B - Con Entorno Virtual Activado:
──────────────────────────────────────────
PowerShell: .\venv\Scripts\Activate.ps1
             python main.py

CMD:         venv\Scripts\activate
             python main.py

🆘 VERIFICACIONES IMPORTANTES
═══════════════════════════════════════════════════════════════════════════════════

✓ ¿Python está instalado?
  python --version
  (Debería mostrar 3.8 o superior)

✓ ¿Las dependencias están instaladas?

  Abre .env con: notepad .env
  Verifica que dice: DISCORD_TOKEN=tu_token_real (sin comillas)

✓ ¿El bot está invitado al servidor?
  Ve a: https://discord.com/developers/applications
  OAuth2 > URL Generator > Scopes: [bot] > Permissions: [administrator]
  Copia URL y abre en navegador

🚀 CREAR ARCHIVO PARA EJECUTAR CON DOBLE CLIC (Windows)
═══════════════════════════════════════════════════════════════════════════════════

1. Crea un archivo nuevo llamado "iniciar.bat" en la carpeta del proyecto

2. Copia y pega esto en el archivo:

@echo off
cd /d "%~dp0"
if exist venv\Scripts\activate.bat (
    call venv\Scripts\activate.bat
)
python main.py
pause

3. Guarda (Ctrl+S)

4. Ahora puedes hacer doble clic en "iniciar.bat" para ejecutar el bot

❌ ERRORES COMUNES Y SOLUCIONES
═══════════════════════════════════════════════════════════════════════════════════

ERROR: "DISCORD_TOKEN not found in .env file!"
───────────────────────────────────────────────
Solución:
  1. Verifica que existe .env (no .env.example)
  2. Abre .env con: notepad .env
  3. Asegúrate que tiene: DISCORD_TOKEN=tu_token
  4. Guarda y cierra
  5. Reinicia el bot


ERROR: "No module named 'discord'"
──────────────────────────────────
Solución:
  pip install -r requirements.txt


ERROR: "Connection refused" o "Invalid token"
──────────────────────────────────────────────
Solución:
  1. Obtén un nuevo token en: https://discord.com/developers/applications
  2. Cópialo completo (sin espacios)
  3. Actualiza .env con: DISCORD_TOKEN=tu_nuevo_token
  4. Reinicia el bot


ERROR: "Module not found: main" (cuando ejecutas desde otra carpeta)
───────────────────────────────────────────────────────────────────
Solución:
  Ejecuta DESDE la carpeta c:\Users\teo72\Downloads\teobot
  cd c:\Users\teo72\Downloads\teobot
  python main.py


ERROR: Los cogs no cargan
─────────────────────────
Solución:
  1. Verifica que los archivos .py están en: cogs/
  2. Verifica que NO tienen errores de sintaxis
  3. Reinicia el bot
