📦 REQUISITOS PREVIOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✓ Python 3.8+ instalado
✓ Token de bot Discord (obtén en https://discord.com/developers/applications)
✓ Permiso para invitar bots a tu servidor de Discord


🚀 PASOS DE INSTALACIÓN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  ABRE POWERSHELL O CMD EN LA CARPETA DEL PROYECTO

   Windows + R → cmd → Enter
   o
   En Windows Explorer, shift+clic derecho en la carpeta → "Abrir PowerShell aquí"
   o
   cd c:\Users\teo72\Downloads\teobot


2️⃣  CREA UN ENTORNO VIRTUAL (Recomendado pero opcional)

   ► PowerShell:
     python -m venv venv
     .\venv\Scripts\Activate.ps1

   ► CMD:
     python -m venv venv
     venv\Scripts\activate


3️⃣  INSTALA LAS DEPENDENCIAS

   pip install -r requirements.txt

   Espera a que veas "Successfully installed discord.py-2.3.2 python-dotenv-1.0.0 aiosqlite-0.19.0"


4️⃣  CONFIGURA EL TOKEN

   Opción A - Si el archivo .env ya existe:
   ├─ Abre .env con Notepad
   └─ Reemplaza: DISCORD_TOKEN=tu_token_aqui
                 Por tu token real (sin comillas)

   Opción B - Si no existe .env:
   ├─ Copia .env.example a .env
   │  Windows: copy .env.example .env
   ├─ Abre .env con Notepad
   └─ Reemplaza: DISCORD_TOKEN=tu_token_aqui


5️⃣  EJECUTA EL BOT

   python main.py

   ✅ Deberías ver:
      ✅ Database initialized
      ✅ Loaded cog: moderation
      ✅ Loaded cog: welcome
      ✅ Loaded cog: roles
      ✅ Loaded cog: triggers
      ✅ Bot logged in as TeoBot#XXXX


6️⃣  INVITA EL BOT A TU SERVIDOR (si no lo has hecho)

   ├─ Ve a: https://discord.com/developers/applications
   ├─ Selecciona tu aplicación
   ├─ OAuth2 → URL Generator
   ├─ Scopes: [✓] bot
   ├─ Permissions: [✓] administrator
   ├─ Copia la URL y abre en navegador
   └─ Selecciona tu servidor y autoriza


7️⃣  PRUEBA UN COMANDO

   En tu servidor de Discord:
   /serverinfo    (Para ver información del servidor)
   /userinfo      (Para ver tu información)

📚 COMANDOS RÁPIDOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔒 MODERACIÓN
  /lock                         → Bloquea el canal
  /unlock                       → Desbloquea el canal
  /tempmute @usuario 60         → Silencia por 60 segundos
  /rolve @usuario @rol          → Da/quita un rol
  /userinfo @usuario            → Info del usuario
  /serverinfo                   → Info del servidor


🎉 BIENVENIDA
  /set_welcome #canal "Bienvenido {user}"        → Configura bienvenida
  /set_farewell #canal "Adiós {user}"            → Configura despedida
  /test_welcome                                   → Prueba el mensaje


⭐ ROLES Y AUTOROLES
  /add_autorole @role                   → Autorole automático
  /remove_autorole @role                → Elimina autorole
  /list_autoroles                       → Ver autoroles
  /add_reaction_role 1234567890 👍 @role → Reaction role
  /remove_reaction_role 1234567890 👍   → Elimina reaction role


🔔 TRIGGERS (Respuestas automáticas)
  /add_trigger hola "¡Hola {user}!"                → Agrega trigger
  /remove_trigger hola                             → Elimina trigger
  /list_triggers                                   → Ver triggers

⚡ CREAR BATCH PARA INICIAR FÁCIL (Windows)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Crea un archivo llamado "iniciar.bat" en la carpeta del proyecto
2. Copia y pega esto:

   @echo off
   cd /d "%~dp0"
   if exist venv\Scripts\activate.bat (
       call venv\Scripts\activate.bat
   )
   python main.py
   pause

3. Guarda el archivo
4. Haz doble clic en "iniciar.bat" para ejecutar el bot

❌ SOLUCIÓN DE PROBLEMAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problema: "DISCORD_TOKEN not found in .env file!"
Solución: Verifica que .env existe y contiene: DISCORD_TOKEN=tu_token_real

Problema: "No module named 'discord'"
Solución: Ejecuta: pip install -r requirements.txt

Problema: "Connection refused / Invalid token"
Solución: Verifica que tu token es correcto y está dentro de comillas

Problema: El bot no carga los cogs
Solución: Asegúrate que los archivos están en cogs/ y terminan en .py

Problema: "python: command not found"
Solución: Python no está en PATH. Reinstala Python y marca "Add Python to PATH"
