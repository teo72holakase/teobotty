📚 COMANDOS DISPONIBLES POR SISTEMA
═════════════════════════════════════════════════════════════════════════════════

🔒 MODERACIÓN (Requiere permisos):
   /lock                           Bloquea el canal
   /unlock                         Desbloquea el canal
   /tempmute @usuario 60           Silencia por 60 segundos
   /rolve @usuario @rol            Da/quita un rol
   /userinfo @usuario              Información del usuario
   /serverinfo                     Información del servidor

🎉 BIENVENIDA (Requiere admin):
   /set_welcome #canal "Bienvenido {user}"
   /set_farewell #canal "Adiós {user}"
   /test_welcome

⭐ AUTOROLES (Requiere permisos):
   /add_autorole @rol              Agregar autorole
   /remove_autorole @rol           Eliminar autorole
   /list_autoroles                 Ver autoroles

🎯 REACTION ROLES (Requiere permisos):
   /add_reaction_role 123456789 👍 @rol    Agregar reaction role
   /remove_reaction_role 123456789 👍      Eliminar reaction role

🔔 TRIGGERS (Requiere admin):
   /add_trigger "hola" "¡Hola {user}!"    Agregar respuesta automática
   /remove_trigger "hola"                  Eliminar trigger
   /list_triggers                          Ver triggers

⚙️ CREAR UN ATAJO PARA EJECUTAR CON DOBLE CLIC (Opcional)
═════════════════════════════════════════════════════════════════════════════════

1. Crea un archivo llamado "iniciar.bat" en la carpeta del proyecto
2. Abre tu editor de texto y pega esto:

   @echo off
   cd /d "%~dp0"
   if exist venv\Scripts\activate.bat (
       call venv\Scripts\activate.bat
   )
   python main.py
   pause

3. Guarda como "iniciar.bat"
4. ¡Listo! Ahora haz doble clic en iniciar.bat para ejecutar el bot
